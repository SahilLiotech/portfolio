# Sahil Pathan — portfolio

My personal site: https://portfolio-virid-eta-76.vercel.app

A single page about my work as a Flutter developer (experience, the FoodChow apps I work on, skills, contact).

Built with Next.js (App Router), React, TypeScript and Tailwind CSS. Deployed on Vercel.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build with type checking
```
